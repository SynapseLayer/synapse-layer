# Quick Start

One command. Or pick the path that fits your stack.

## Option 0: 1-command installer (fastest)

```bash
curl -fsSL https://forge.synapselayer.org/install/smithery | bash
```

It asks which client (Claude Desktop, Cursor, opencode, Codex, Gemini…) and your Connect Token, then installs the server automatically. Your token is typed hidden — it never appears in shell history.

On [forge.synapselayer.org](https://forge.synapselayer.org) → **Connect**, the **Smithery** card copies a one-liner that already includes your token:

```bash
curl -fsSL https://forge.synapselayer.org/install/smithery | bash -s -- sk_connect_YOUR_TOKEN
```

The token travels as a shell argument — never in the URL — and the installer detects it automatically, so the only thing left is typing your client.

## Option 1: Smithery (Recommended for MCP)

The fastest path for Claude Desktop, Cursor, OpenAI Codex, and any MCP-compatible client:

```bash
npx -y @smithery/cli@latest install @synapselayer/synapselayer \
  --client <your-client> \
  --config '{"connect_token": "sk_connect_YOUR_TOKEN"}'
```

Replace `<your-client>` with one of: `claude`, `cursor`, `opencode`, `codex`, `gemini-cli`, `cline`, `windsurf`. Or open the [Smithery listing](https://smithery.ai/servers/synapselayer/synapselayer), click **Install**, and paste the generated command.

Connect your agent on [forge.synapselayer.org](https://forge.synapselayer.org) → **Connect** to get your `sk_connect_...` token.

Your agent immediately gets access to **13 MCP tools**:

| Tool | What It Does |
|---|---|
| `health_check` | System health, version, and capability report (public — no token needed) |
| `initialize_context` | Warm-up memory context at session start |
| `recall` / `recall_memory` | Semantic / temporal / priority memory retrieval |
| `search` | Full-text search across agents |
| `list_memories` | List stored memory metadata |
| `save_to_synapse` / `save_memory` / `store_memory` | Persist memory with the full security pipeline (AES-256-GCM at rest) |
| `process_text` | Auto-detect decisions, milestones, alerts from free text |
| `memory_feedback` | Adjust trust scoring on a memory |
| `neural_handover` | Transfer contextual state between agents |
| `slo_report` | Uptime and SLO metrics (admin token) |

## Option 2: Direct MCP Connection

Add to your MCP client configuration:

```json
{
  "mcpServers": {
    "synapse-layer": {
      "url": "https://forge.synapselayer.org/api/mcp"
    }
  }
}
```

<Tip>
  This connects to the hosted endpoint. `health_check` and `initialize_context` work without a token; authenticated tools require your `sk_connect_...` token passed as the `x-connect-token` header (or `Authorization: Bearer` for compatibility).
</Tip>

## Option 3: Python SDK

```bash
pip install synapse-layer
```

```python
from synapse_layer import Synapse

syn = Synapse(token="sk_connect_YOUR_TOKEN", agent_id="my-agent")

# Store a memory (full security pipeline runs automatically)
syn.store("User prefers dark mode and speaks Portuguese")

# Recall with semantic search
for r in syn.recall("user preferences"):
    print(f"  {r.content}")
```

## Verify Installation

```bash
curl -s -X POST https://forge.synapselayer.org/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

Expected: JSON response with **13 tools** listed, and no authentication required for the public `health_check` tool.
