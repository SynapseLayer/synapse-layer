## How It Works

The separation is enforced at the code level via the **Plugin Architecture**:

```python
# OSS mode (default) — uses built-in defaults
engine = AutoSaveEngine(database=db, redactor=redact)

# PRO mode — auto-loads synapse-layer-pro if installed
engine = AutoSaveEngine(database=db, redactor=redact, mode="pro")
```

Set `SYNAPSE_MODE=pro` to enable. If `synapse-layer-pro` is not installed, a warning is emitted and OSS defaults are used.
