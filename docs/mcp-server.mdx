# MCP Server

Synapse Layer exposes a fully MCP-compatible server with 4 tools for autonomous memory management.

## Endpoint

```
POST https://forge.synapselayer.org/api/mcp
```

Protocol: **JSON-RPC 2.0** over HTTP, conforming to [MCP specification](https://modelcontextprotocol.io) (`protocolVersion: 2024-11-05`).

## Tools

### process_text

Scans free-form text for auto-save triggers. Detected events pass through the full pipeline: policy evaluation, PII/secret redaction, deduplication, and persistence.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "process_text",
    "arguments": {
      "text": "We decided to pivot to enterprise B2B after the seed round",
      "project": "SYNAPSE_LAYER",
      "conversation_id": "conv-123",
      "message_id": "msg-456"
    }
  }
}
```

| Parameter | Type | Required | Description |
|---|---|:---:|---|
| `text` | string | ✅ | Free-form text to scan for triggers |
| `project` | string | | Project identifier (auto-detected if omitted) |
| `source` | string | | Source identifier (default: `auto`) |
| `conversation_id` | string | | Conversation ID for tracing |
| `message_id` | string | | Message ID for tracing |
| `url` | string | | Source URL for tracing |

### save_to_synapse

Directly save a structured memory event with full security pipeline.

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "save_to_synapse",
    "arguments": {
      "content": "Launched v2.0 to production",
      "project": "OFFLY",
      "type": "[MILESTONE]",
      "importance": 4,
      "tags": ["launch", "production"]
    }
  }
}
```

| Parameter | Type | Required | Description |
|---|---|:---:|---|
| `content` | string | ✅ | Memory content to store |
| `project` | string | ✅ | Project identifier |
| `type` | string | | Event type (see below) |
| `importance` | number | | 1–5 (default: 3) |
| `tags` | string[] | | Tags for categorization |

**Event types:** `[MILESTONE]`, `[DECISION]`, `[ALERT]`, `[AUTO-STRAT]`, `[AUTO-OP]`, `[AUTO-INSIGHT]`, `[AUTO-DECISION]`, `[AUTO-CONTEXT]`, `[MANUAL]`

### backfill_embeddings

Process pending embedding jobs for recently stored memories.

```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "backfill_embeddings",
    "arguments": {
      "limit": 20
    }
  }
}
```

| Parameter | Type | Required | Description |
|---|---|:---:|---|
| `limit` | number | | Max jobs to process (1–50, default: 10) |

### health_check

Returns system health, version, and capability report.

```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "method": "tools/call",
  "params": {
    "name": "health_check",
    "arguments": {}
  }
}
```

## MCP Handshake

```json
{
  "jsonrpc": "2.0",
  "id": 0,
  "method": "initialize"
}
```

Response:

```json
{
  "jsonrpc": "2.0",
  "id": 0,
  "result": {
    "protocolVersion": "2024-11-05",
    "capabilities": { "tools": { "listChanged": false } },
    "serverInfo": { "name": "synapse-layer", "version": "1.0.7" }
  }
}
```

## Self-Hosted Deployment

For full persistence with your own database, deploy the [mcp-autosave bridge](https://github.com/SynapseLayer/synapse-layer/tree/main/mcp-autosave) with Supabase:

```bash
cd mcp-autosave
cp .env.example .env
# Configure SUPABASE_URL and SUPABASE_KEY
python server.py
```

This gives you the same 4 tools with real database persistence, embedding generation, and RLS security.
