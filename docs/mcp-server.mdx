# MCP Server

Synapse Layer exposes a fully MCP-compatible server with 13 tools for autonomous memory management.

## Endpoint

```
POST https://forge.synapselayer.org/api/mcp
```

Protocol: **JSON-RPC 2.0** over HTTP, conforming to [MCP specification](https://modelcontextprotocol.io).

## Auth Model

- **Public tools** (no token): `health_check`, `initialize_context`, `tools/list`
- **Authenticated tools**: everything else — requires `x-connect-token: sk_connect_...` header

## Tools

### Recall (`recall` / `recall_memory`)

Retrieve relevant persisted memory using semantic, temporal, priority, or hybrid routing.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "recall",
    "arguments": {
      "query": "user preferences",
      "limit": 10
    }
  }
}
```

### Store (`save_to_synapse` / `save_memory` / `store_memory`)

Persist a memory with the full security pipeline — PII/secret redaction, deduplication, and AES-256-GCM encryption at rest.

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "save_to_synapse",
    "arguments": {
      "content": "Launched v2.0 to production",
      "project": "OFFLY",
      "type": "[MILESTONE]",
      "tags": ["launch", "production"]
    }
  }
}
```

**Event types:** `[MILESTONE]`, `[DECISION]`, `[ALERT]`, `[AUTO-STRAT]`, `[AUTO-OP]`, `[AUTO-INSIGHT]`, `[AUTO-DECISION]`, `[AUTO-CONTEXT]`, `[MANUAL]`

### process_text

Scan free-form text for auto-save triggers. Detected events pass through the full pipeline: policy evaluation, PII/secret redaction, deduplication, and persistence.

```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "process_text",
    "arguments": {
      "text": "We decided to pivot to enterprise B2B after the seed round",
      "project": "SYNAPSE_LAYER"
    }
  }
}
```

### search

Full-text search across agents.

### list_memories

List memory metadata with pagination and governance limits.

### memory_feedback

Submit feedback to adjust trust scoring for stored memories.

### health_check

Returns system health, version, and capability report. **Public — no token required.**

```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "method": "tools/call",
  "params": {
    "name": "health_check",
    "arguments": {}
  }
}
```

### initialize_context

Initialize a persistent memory context for a conversation or agent session. **Public — no token required.**

### slo_report

Return uptime and SLO metrics (requires admin token).

## MCP Handshake

```json
{
  "jsonrpc": "2.0",
  "id": 0,
  "method": "initialize"
}
```

Response:

```json
{
  "jsonrpc": "2.0",
  "id": 0,
  "result": {
    "protocolVersion": "2024-11-05",
    "capabilities": { "tools": { "listChanged": false } },
    "serverInfo": { "name": "synapse-layer", "version": "2.4.6" }
  }
}
```
